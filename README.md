# AnnA — сайт ателье

Лёгкий одностраничный сайт на HTML, CSS и JavaScript. Никаких установок не требуется: откройте `index.html` в браузере.

## Что работает

- выбор услуги, даты и 45-минутного слота;
- график: будни 18:00–21:00, суббота 11:00–17:00, воскресенье — выходной;
- проверка полей, исключение прошедших и уже занятых слотов;
- готовое сообщение с данными клиента для WhatsApp владельца;
- отмена записи через ссылку из подтверждения;
- адаптация под мобильные экраны.

## Перед публикацией

Сейчас записи хранятся только в браузере посетителя — это демо-режим. Для настоящего сайта подключите общую базу и серверный API по схеме из [server/README.md](server/README.md), затем разместите папку проекта на хостинге и подключите домен.

Изображения загружаются из Unsplash как временные тематические иллюстрации. Замените их реальными работами ателье, когда они появятся.
