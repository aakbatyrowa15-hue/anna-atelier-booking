# Подключение общей записи перед публикацией

Сайт сейчас работает как интерактивный макет: занятые слоты сохраняются в браузере посетителя. Это позволяет проверить весь путь клиента без сервера, но не защищает слот от записи с другого телефона.

Перед публикацией подключите базу данных и три конечные точки:

- `GET /api/appointments?date=YYYY-MM-DD` — возвращает занятые слоты выбранного дня;
- `POST /api/appointments` — принимает услугу, дату, время, имя, телефон и комментарий. На сервере повторно проверяет доступность времени, сохраняет запись и отправляет владельцу уведомление;
- `PATCH /api/appointments/:id` — отменяет или переносит запись по защищённому одноразовому токену.

Шаблон обработчика находится в `api/appointments.js`. Его можно перенести в папку API выбранного хостинга (например, `api/` в Vercel) и заменить отмеченные комментариями места на запросы к базе данных.

Рекомендуемый минимум: Supabase или Firebase для базы, серверная функция Vercel/Netlify для API и WhatsApp Business Cloud API для подтверждений. Номер владельца: `+7 708 442 80 28`.

Не передавайте ключ WhatsApp Business API в браузер. Он должен храниться только в переменных окружения сервера.
